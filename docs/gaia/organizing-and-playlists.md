# Organizing & Playlists

<!-- Outline scaffold — Phase 2+ fills full prose -->

Browse, analyze, group, and curate sounds across vaults without breaking physical directory ownership.

---

## Outline

- **Managed Import Inspector**: Importing individual files, folders, or ZIPs (`Import assets` or drag & drop); auto-detection of collections, sample packs, and multitracks.
- **Folders vs. Dissolve Folder**:
  - Normal vault folders map 1-1 to directories on disk; `Delete` removes the folder and its contents (safely preserving external references and project-referenced items).
  - **Dissolve folder** (`Selection` / context menu) moves direct children into the parent folder and removes only the folder container.
- **Filtering & Metadata Analysis**: Type chips (`audio`, `track`, `sample`, `folder`, `project`, etc.), tag chips, search bar, and **Analyze metadata** (BPM, key, duration).
- **Cross-Vault Playlists**: Creating ordered horizontal playlists (`Playlists → New playlist…` or sidebar `+`) that span vaults without moving files or changing vault ownership.
