# 01 — First Vault in GAIA

<!-- Outline scaffold — Phase 2 fills full prose -->

Set up a tiny playable library in GAIA (or load local samples directly in SIN) before opening your first patch.

---

## 1. Create or Pick a Vault in GAIA (`:8001`)

- Open `Vault → Create vault` (e.g., `tutorial`) or choose an existing vault from the vault picker.
- Understand that each vault maps 1-1 to its own folder under `assets/vaults/<storage_key>/`.

## 2. Import Starter or Local Sounds

- Click **Import assets** (or `File → Import assets`, or drag & drop files/folders onto the asset list).
- Import either the starter kit *(Phase 2)* or a small folder containing 1–2 loops and a few drum one-shots (kick, snare, hat).
- Wait for registration and metadata analysis (BPM, key, duration) to finish.

## 3. Preview & Confirm in SIN (`:8000`)

- Click any item in GAIA and press `Space` (or the bottom transport `▶`) to audition it.
- Switch to SIN (`:8000`) and press `L` (or `Library → Open Library`) to browse the same vault read-only.

## 4. Using SIN Without GAIA (Standalone Local Assets)

> **Tip:** Tutorial patches also support loading local audio files directly onto `Sample` nodes (e.g., via `Asset File` or file drop) when running SIN without an active GAIA connection.
