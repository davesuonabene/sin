Keyboard shortcuts, toolbar controls, menus, and slot interactions in the SIN node canvas.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Space` | Play / Pause transport |
| `L` | Toggle Library panel |
| `P` | Toggle Properties / Inspector panel |
| `Ctrl/Cmd + O` | Open workspace (`saves/` or local `.json`) |
| `Ctrl/Cmd + S` | Save current workspace |
| `Ctrl/Cmd + C` / `Ctrl/Cmd + V` | Copy / Paste active slot when focused in the Inspector / slot strip |
| `Delete` / `Backspace` | Delete selected cables, selected modifier badge, or focused slot (when > 1 slot exists) |
| `Esc` | Deselect selected nodes and cables |

## Header Menus & Toolbar

- **File**: `New`, `Open...`, `Open Recent`, `Save`, `Save As...`, `Download selected audio`.
- **Library**: `Open Library`, `Refresh Library`, `Auto-preview`.
- **Render**: `Render Flagged Nodes`, `Render Selected Nodes`, `Render Most Parent Nodes`, `Render All Nodes`.
- **Right Toolbar**: Play transport, **Refresh (`↻`)**, **Global Seed** (`0, 1, 2...`), **Global Seed Lock**, **Global Freeze**, and Inspector toggle (`P`).
