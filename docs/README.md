# SIN + GAIA Documentation

**SIN** is the visual audio-node workspace and composition editor; **GAIA** is the standalone library manager that imports, indexes, previews, and organizes your audio vaults. Together they form one workflow—and SIN starter patches also support loading local audio samples directly onto nodes without a GAIA connection.
